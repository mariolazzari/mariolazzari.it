# Mario Lazzari — Personal Website

Personal portfolio and website of Mario Lazzari, Senior Full Stack Developer with 29 years of experience building web applications and software solutions.

**Website:** [mariolazzari.it](https://mariolazzari.it)

- Software architecture, performance, and maintainable code.

## Quick Start

### Prerequisites

Make sure you have the following tools installed:

- Node.js (LTS)
- npm
- Git

### Installation

Clone the repository:

```bash
git clone <repository-url>
cd <project-directory>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Setup

```sh
APP_NAME=mariolazzari
APP_PORT=

POSTGRES_USER=
POSTGRES_PASSWORD=
POSTGRES_DB=
```
